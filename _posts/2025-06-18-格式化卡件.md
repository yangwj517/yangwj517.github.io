# 格式化命令


## 1100
* 使用1GB存储
  
```cmd
C:\Windows\system32>format e:/a:16k /fs:FAT
```

>
> Insert new disk for drive E:
>
> and press ENTER when ready...
>
> The type of the file system is FAT.
>
> Verifying 976.5 MB
>
> 12 percent completed.
