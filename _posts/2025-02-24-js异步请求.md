# js原生+流行 异步请求

## 一、原生 JavaScript

### 1. XMLHttpRequest(传统方式)
```javascript
// GET 请求
const xhrGet = new XMLHttpRequest();
xhrGet.open('GET', 'https://api.example.com/data');
xhrGet.onload = function() {
  if (xhrGet.status === 200) {
    console.log(JSON.parse(xhrGet.response));
  } else {
    console.error('请求失败');
  }
};
xhrGet.send();

// POST 请求
const xhrPost = new XMLHttpRequest();
xhrPost.open('POST', 'https://api.example.com/data');
xhrPost.setRequestHeader('Content-Type', 'application/json');
xhrPost.onload = function() {
  console.log(JSON.parse(xhrPost.response));
};
xhrPost.send(JSON.stringify({ key: 'value' }));
```
### 2. Fetch API(现代浏览器原生支持)
```javascript
// GET 请求
fetch('https://api.example.com/data')
  .then(response => {
    if (!response.ok) throw new Error('请求失败');
    return response.json();
  })
  .then(data => console.log(data))
  .catch(error => console.error(error));

// POST 请求
fetch('https://api.example.com/data', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ key: 'value' })
})
  .then(response => response.json())
  .then(data => console.log(data));
```
## 二、流行框架和库
### 1. Axios(独立Http库)
```javascript
// 安装：npm install axios
import axios from 'axios';

// GET 请求
axios.get('https://api.example.com/data')
  .then(response => console.log(response.data))
  .catch(error => console.error(error));

// POST 请求
axios.post('https://api.example.com/data', { key: 'value' })
  .then(response => console.log(response.data));
```

### 2. jQuery(传统库)
```javascript
// 需引入 jQuery 脚本
// GET 请求
$.ajax({
  url: 'https://api.example.com/data',
  method: 'GET',
  success: data => console.log(data),
  error: err => console.error(err)
});

// POST 请求
$.ajax({
  url: 'https://api.example.com/data',
  method: 'POST',
  contentType: 'application/json',
  data: JSON.stringify({ key: 'value' }),
  success: data => console.log(data)
});
```

### 3. Vue(组合式API+Axios)
```javascript
// 安装：npm install axios
import { ref } from 'vue';
import axios from 'axios';

// 在 Vue 组件中
const data = ref(null);
const fetchData = async () => {
  try {
    const response = await axios.get('https://api.example.com/data');
    data.value = response.data;
  } catch (error) {
    console.error(error);
  }
};

// 发送 POST 请求
const postData = async () => {
  await axios.post('https://api.example.com/data', { key: 'value' });
};
```

### 4. React(函数组件+Fetch)
```javascript
import { useState, useEffect } from 'react';

function App() {
  const [data, setData] = useState(null);

  // GET 请求
  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(res => res.json())
      .then(data => setData(data));
  }, []);

  // POST 请求
  const handleSubmit = async () => {
    const response = await fetch('https://api.example.com/data', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ key: 'value' })
    });
    const result = await response.json();
    console.log(result);
  };

  return <div>{/* 渲染数据 */}</div>;
}
```

### 5. Angular（HttpClient）
```javascript
// 安装：Angular 自带 HttpClientModule
import { HttpClient } from '@angular/common/http';

// 在服务类中
@Injectable({ providedIn: 'root' })
export class DataService {
  constructor(private http: HttpClient) {}

  // GET 请求
  getData() {
    return this.http.get('https://api.example.com/data');
  }

  // POST 请求
  postData() {
    return this.http.post('https://api.example.com/data', { key: 'value' });
  }
}

// 在组件中调用
this.dataService.getData().subscribe(data => console.log(data));
```
## 三、其他现代工具
### 1. Svelte(使用Fetch)
```javascript
<script>
  let data;

  // GET 请求
  fetch('https://api.example.com/data')
    .then(res => res.json())
    .then(json => data = json);
</script>

<div>{data?.message}</div>
```
### 2. Nuxt.js(服务端请求)
```javascript
// 在 asyncData 或 fetch 钩子中
export default {
  async asyncData({ $axios }) {
    const data = await $axios.$get('https://api.example.com/data');
    return { data };
  }
};
```

## 四、总结对比

| 方法/框架 | 特点 |
| :----: | :---- | 
| 原生Fetch | 现代浏览器原生支持，无需依赖，但需手动处理JSON和错误 |
| Axios | 功能丰富（自动转换JSON、拦截和取消请求） |
| jQuery | 旧项目常见，语法简介，但逐渐被现代技术替代 |
| Vue/React | 结合Axios 或 Fetch ，推荐在组件生命周期中管理数据 |
| Angular | 强类型支持(TypeScript) ，依赖注入, 内置HttpClient模块 |

## 五、选择建议
1. 简单场景 : 优先使用原生 Fetch
2. 复杂项目 :  选择Axios(拦截器、错误处理更加完善)
3. 框架集成 :  直接使用对应框架的推荐方式（如Angular的HttpClient）
4. 旧项目维护 : 可能需继续沿用jQuery.ajax
