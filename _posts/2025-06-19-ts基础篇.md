# TS特性

## 兼容

* 是JavaScript的超集。 

``` ts

tcs  ?.ts  

```

> 上述命令可将ts代码直接编译为js使用


## 一、类型声明

### 1.类型

* number
* string
* boolean
* array
* boolean
* tuple  : 元组 ？
* ...


### 2.显式

```ts 

let age : number = 18 ;  // 显式定义类型  number

```

### 3.隐式 

```ts

let name = "ywj" ;  // 隐式类型  -  不直接声明类型 ， TS 会自行根据赋值对变量类型进行推断

```

## 二、类

### 1. 访问控制修饰符 

* public   默认的（当不使用修饰符是默认使用此修饰符） 
* protected 
* private 

### 2. 类定义

```ts

class Person {

    // 字段
    protected name : string ;
    private age : number ;

    // 构造函数
    constructor(name:string , age : number){
        this.name = name ;
        this.age = age ;
    }

    // 方法
    public sleep(time : number ) : boolean {
        // ... 具体实现内容
    }

}

``` 

### 3. 实例化

```ts

var zhangsan = new Person("zhangsan"，19) ;

``` 

### 4. 抽象类 

```ts 

abstract class Person {
    abstract sleep() : void ；
}

```

> 抽象类不可实例化 ，只能通过子类继承后，再对子类进行实例化

### 5. 继承

```ts

class Boy extens Person {

}

``` 
## 三、接口

### 1.定义 

```ts

interface Cat {
    name : string ;
    gender : string ;
    age : number ;
}

```

### 2.实现

```ts

class ywjsCat implements Cat {
    name : string ;
    gender : string ;
    age : number ;
    eat() : void ;  // 方法接口
}

``` 


## 四、泛型

```ts

class Test<T> {}   // 泛型类


funcation test<T>(x : T):T{}  // 泛型函数


interface Test<T> {}  //  泛型接口


funcation test<T extends Person>(name : string) : T {}  // 约束泛型类型必须继承 Person 

```
